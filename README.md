# List-Management-in-Csharp
﻿About

This is a simple C# console application that helps users manage a list of numbers. It allows users to add numbers, display the list, calculate the mean, and find the smallest and largest numbers. The program uses a simple menu to let users choose what they want to do.

What I Learned

In this project, I learned how to use if statements to check conditions and switch statements to handle user choices. I also practiced working with lists, using loops, getting user input, and performing calculations. This project helped me understand how to combine these concepts to build a simple, interactive program.
